# 合作申请同步到飞书

部署顺序：先在目标数据库执行 `sql/20261027_cooperation_feishu_sync.sql`，再部署后端和后台管理网站。迁移只增加一个商单绑定字段和两张映射表，保留现有商单、接单与申请数据。

后端沿用用户同步的 `FEISHU_APP_ID`、`FEISHU_APP_SECRET` 和 `FEISHU_WIKI_BASE_URL`。另设：

```dotenv
FEISHU_COOPERATION_SYNC_ENABLED=true
FEISHU_COOPERATION_WIKI_SPACE_ID=7701281082951437603
```

平台超管在商单编辑页绑定“快组商业化”知识库中的 Docx 文档。系统在同步时通过飞书 API 核验节点类型和知识库 ID。现已给应用 `cli_aae70d521bf81d02` 授权“明略科技CoCraft产品”文档；其他商单文档需要分别给该应用文档级编辑权限。

审核页的“同步到飞书”会直接在商单文档下创建学校专属知识库多维表格。字段沿用用户导出表的 15 列，并增加申请结果（未处理、成功、失败）、轮次、申请时间、审核时间和审核备注。只同步真实提交过的申请。

此前误建在云空间或使用旧字段的申请表不会被删除；下次同步会新建正确的知识库表格并重建申请映射。旧表格保留供管理员核对。新表格沿用飞书默认权限，您可在表格生成后自行设置成员和访问权限。

同步包含该校合作下的全部申请轮次和当前审核状态。再次点击会更新已有记录，并删除本地已不存在的申请对应的飞书记录。申请记录使用 UUIDv4 幂等键；记录写入结果无法确认时，会保留同一幂等键以便安全重试。旧版本生成的非 UUID 幂等键会在重试时替换。知识库节点或数据表的创建结果无法确认时，仍需技术人员先核对远端内容和本地映射，避免重复创建。

可用以下只读 SQL 验证迁移：

```sql
SHOW COLUMNS FROM commercial_order LIKE 'feishu_wiki_node_token';
SHOW TABLES LIKE 'cooperation_feishu_target';
SHOW TABLES LIKE 'cooperation_feishu_record';
```

## 2026-11-08 合并审查修复

字段核对按必需字段名称匹配，允许管理员调整列顺序、增加人工维护列；字段列表分页读完后再检查。分页失败或响应不完整时终止本轮同步，不据此新建表格。必需字段缺失、类型或必需选项不兼容时仍沿用原有结构迁移行为。

首次同步在短事务中锁定商单、重新核对当前文档绑定并提交 running 状态，然后才启动远端任务。文档换绑使用同一商单行锁；已有申请表、同步中或结果待核对时禁止换绑（包括尚未保存 app_token 的创建窗口）。不更换绑定的商单名称、说明等编辑不受此限制。事务内没有飞书网络请求。

本次修复不新增接口、路由、数据库字段或迁移；不改申请审核、通知投递、用户同步及消息中心逻辑。回归测试覆盖字段重排与扩展、分页异常、真正不兼容的字段、启动提交与回滚、换绑保护和普通商单编辑。

## 2026-11-09 合并前复审修复

合作知识库表格、数据表的创建失败现在区分“明确拒绝”和“结果不确定”：收到完整的非零飞书错误码，且为 HTTP 401/403/429，或已确认的知识库权限（131006）、多维表格权限（1254302）、API scope（99991672）拒绝时，保存为 failed。修正授权或等待限流解除后，沿用原有同步按钮重新发起；已保存的学校 Base 会继续复用。HTTP 408/5xx、其他未知错误、网络中断、异常响应、缺少远端 ID，以及远端创建成功但本地映射写入失败，仍进入 needs_attention，不能盲目重建。保留原错误链用于记录脱敏错误码。旧版本已进入 needs_attention 的任务不能仅凭本地空映射推断“远端未创建”，仍需先人工核对，不能自动解锁。

OpenAPI 补齐现有合作飞书同步 GET/POST 路径、同步状态响应，以及商单 ended 状态、模板、已接单学校、合作关联商单状态和飞书绑定字段。模板省略时保留、null 时清除；绑定省略或 null 时保留、空字符串时清除。平台超管等没有学校归属范围的商单列表，其 claimedSchoolIds 按实际实现允许 null。契约测试覆盖这些请求/响应边界。

本次只修改合作创建错误分类与既有接口契约，不新增运行时路由、状态、依赖、数据库字段或迁移，不改变申请审核、消息通知、支付、佣金、用户飞书同步或客户端导航。原分支的数据库迁移仍须先于后端上线执行；即使关闭合作飞书同步，普通商单/合作查询也需要对应的新列。权限与错误响应说明参考飞书官方[知识库节点创建](https://open.feishu.cn/document/server-docs/docs/wiki-v2/space-node/create)、[数据表创建](https://open.feishu.cn/document/server-docs/docs/bitable-v1/app-table/create)及[多维表格权限错误](https://open.feishu.cn/document/uAjLw4CM/ukTMukTMukTM/reference/bitable-v1/app-role-member/batch_create)。
