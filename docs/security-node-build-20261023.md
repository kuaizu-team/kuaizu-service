# 后端构建期 Node 安全修复

基线为 main@3fb47fa。原生产构建的 Actions Node 为 22.23.3，Docker builder 为 24.18.1，均低于 2026-10-21 安全发布要求。

CI 验证和标签发布统一读取 .nvmrc 的 22.23.4。Docker builder 使用官方 node:22.23.4-alpine，拷入固定 Go 1.26.10 工具链；不再通过 apk 安装另一个旧 Node。生成 API 前检查实际 Node，CI 同时验证旧补丁、非受支持分支和预发布版本会被拒绝。

最终运行层继续只复制两个 Go 二进制，不包含 Node 或 npm。Go 版本、依赖、业务代码、路由、数据库、端口、镜像身份检查及发布入口均不变。现有验证仍需执行代码生成、Go 测试、vet、源码与最终镜像二进制漏洞扫描。

修复需合入并完成一次生产部署才能替换既有产物；分支验证通过不等于已上线。生产运行时的 Go 漏洞已由此前部署修复，本项关闭的是构建工具链缺口。
